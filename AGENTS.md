# AGENTS.md

Android-only Expo app (WasteWise). Read `README.md` for setup/API contract, `PRD.md`
for behavior, and `DESIGN.md` before changing UI.

## Commands

- Install/run: `bun install`, `bun run start`.
- Full gate: `bun run verify` = `typecheck -> lint -> format:check -> test`. Run after changes.
- Unit tests use Bun (`__tests__/unit/*.test.ts`):
  `bun test __tests__/unit/session-restore.test.ts`
- UI tests use Jest + RNTL (`__tests__/ui/**/*.ui.tsx` only):
  `bunx jest --config jest.config.js __tests__/ui/login.ui.tsx`
- `bun run test` runs both suites. A file ending `.test.tsx` is not picked up by either suite.
- API types are gitignored, so a fresh clone must run `bun run api:generate` before
  typechecking. It reads the sibling repo `../waste-wise-web/backend/swagger.json`
  (regenerate that backend spec first); never edit `src/types/api.generated.ts`.
- Native build/prebuild needs Node LTS: `bun run prebuild --platform android --clean`.
  Google Sign-In works only in a dev/EAS build, not Expo Go.

## Architecture

- Expo Router routes live in `app/`. The auth gate is `Stack.Protected` in
  `app/_layout.tsx`; providers (Query, Theme, Auth) are wired there.
- Path alias `@/*` -> `src/*`. Use `noUncheckedIndexedAccess`-safe TS.
- All HTTP goes through the axios client in `src/api/client.ts`. It attaches
  `X-Client: WasteWise-Mobile`, adds the cached access token, performs one
  refresh-and-retry on 401, and calls the unauthorized handler from `AuthProvider`
  only when the refresh session is invalid. Do not create parallel axios clients or
  call the ML service directly.
- API types come from OpenAPI via `src/types/domain.ts`; server state is TanStack
  Query hooks in `src/hooks/`, keys in `src/api/query-keys.ts`.
- Theme is semantic: use `useTheme()` tokens from `src/theme/tokens.ts`. Never
  hardcode hex/rgba outside `tokens.ts` and the Google brand mark.
- Report submit is two steps: upload media (`POST /media/upload`) then create report.
  Retries must reuse the uploaded `mediaId`; images are compressed to JPEG under 5 MB
  first. AI classification happens server-side only.
- Session restore distinguishes invalid sessions (clear tokens) from transient
  failures (show recovery screen, keep tokens). Preserve this distinction.

## Gotchas

- Bun 1.3.14 only; commit only `bun.lock`. Use `bun --bun` for project scripts where
  configured. Do not add npm/yarn/pnpm lockfiles.
- `.env` is local. `EXPO_PUBLIC_API_URL` must include `/api/v1`;
  `EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID` must match backend `GOOGLE_CLIENT_ID`.
  Preview/production builds fail early if either is missing; cleartext HTTP is
  non-production only.
- `android/`, `ios/`, `.expo/`, `dist/`, `src/types/api.generated.ts` are ignored
  generated output. Do not hand-edit or commit them.
- Brand assets are generated by `scripts/generate-brand-assets.py` from the sibling
  web frontend (needs Python + Pillow), then followed by a clean prebuild.
- UI tests render screens without root providers; they manually mock `@/theme`,
  auth, safe-area, and native modules. Keep that pattern for new UI tests.
- Prettier: single quotes, trailing commas, 80 columns, semicolons. `verify` enforces it.
